# Brief de la landing

## Objetivo

Una persona que llega desde Instagram puede evaluar si Urbana 20 sirve para llevar su notebook y encontrar un camino de compra identificado.

## Público y tono

Personas que llevan una computadora al trabajo o a estudiar. Tono cercano, voseo y afirmaciones respaldadas por la ficha.

## Versión inicial

Portada pública con Ruta Urbana, Urbana 20 y «Primera versión de clase». Esta versión permite verificar GitHub → Railway → navegador. La ficha ampliada, visuales y compra forman parte de la próxima práctica.

## Stack

Markdown para fuentes y wiki. Git y GitHub para versiones. HTML y CSS para la página. Node.js para servir public/. Railway para ejecutar y publicar por HTTPS.

## Verificación

La portada abre desde otro dispositivo. Los estilos cargan. Las solicitudes web de fuentes/ y wiki/ devuelven 404. Una sesión nueva recupera una afirmación y su referencia desde los archivos del repositorio.
