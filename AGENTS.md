# Instrucciones para agentes

1. Leé wiki/index.md, wiki/brief.md y wiki/decisiones.md antes de editar.
2. Verificá afirmaciones comerciales en fuentes/ficha-negocio.md. Citá archivo y fragmento en la respuesta.
3. Conservá las fuentes originales. Para incorporar un documento, guardá procedencia y fecha, sintetizá los datos relevantes y enlazá las páginas afectadas.
4. Señalá contradicciones y consultá al responsable antes de sustituir una decisión aprobada. El equipo docente aprueba este caso ficticio.
5. Actualizá el índice y el registro fechado de decisiones cuando cambie el conocimiento o el alcance. Mantené los pendientes explícitos.
6. Revisá git status antes de editar y la versión vigente antes de integrar cambios de otros agentes. Registrá cada cambio aceptado en un commit.
7. Serví únicamente public/. Verificá portada, estilos y 404 para archivos internos después de cambiar el servidor.
8. Distinguí una prueba local de una prueba en la URL desplegada. Documentá solo resultados observados.
9. El precio de referencia pertenece al caso didáctico. La primera portada no ejecuta cobros. Un enlace real requiere producto e importe aprobados.
